9th step - git commit -m --- to commit the changes and along with the message  --- git commit -m "changes message"

10th step - git push  -- to raise the Pull request for the first time ----  git push origin "current working branch name"

11th step -- compare & pull request - to click on compare and pull request button >>  then create pull request button

12th Step -- git pull  - to fetch the updated code frmo remote repository --- git pull origin main
